StarAt — Everything starts here.

Turn scattered information into action. 把零散信息变成下一步。StarAt 是一款开源、本地优先的 Windows 桌面收集与行动工作台，支持悬浮窗拖放捕获链接、文件与灵感文字，在收件箱整理为待办、笔记与提示，再用今日与日历安排下一步。

下载 StarAt Windows x64 安装包 (v0.1.5) · GitHub 开源仓库

核心能力

  • 悬浮捕获：从当前窗口随手拖入链接、文件、图片或文字，也支持剪贴板粘贴与全局快捷键捕获。
  • 来源与规则：完整保留原始来源，常见内容可由捕获工作流自动识别并转为待办、笔记或提示。
  • 今日与日历：用「今日」聚焦眼前的事，在日历时间块里为后续任务留出空间，数据默认保存在本机 SQLite。

从收下到行动，只需三步

  1. 随手收下：看到有用的内容就拖进桌面悬浮窗，不打断当前思路。
  2. 回头整理：打开收件箱，把新内容归类为待办、笔记或提示。
  3. 择时行动：把要做的事排进日历，再从「今日」开始稳步推进。

Turn scattered information into action. StarAt is a free, open-source, local-first personal capture and planning desktop workspace for Windows (Tauri 2 + Rust + SQLite).
