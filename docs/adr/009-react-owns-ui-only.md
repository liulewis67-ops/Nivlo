# ADR-009 React Owns UI Only

- 状态：Accepted
- 日期：2026-10-09
- 相关文档：架构文档 §3.2、§15、§68；前端规范 §1

## 背景

业务规则一旦写进前端，会与后端重复并产生不一致，也会让多窗口同步变得困难。

## 决策

React 只负责视图、交互、动画、UI 本地状态（Zustand）与查询缓存（TanStack Query）。业务规则、持久化、调度、网络访问全部在 Rust 后端；前端通过生成的 Typed IPC Binding 调用 Use Case，并通过事件更新缓存；前端不发起 HTTP 请求。

## 后果

- 好处：单一事实来源；两个窗口通过事件天然同步；前端可替换。
- 代价 / 风险：交互需要 Optimistic Update 来保证手感；IPC DTO 需要维护。
- 替代方案：前端承载部分业务逻辑（规则重复且易漂移）。
