# ADR-007 Windows-first Cross-platform Strategy

- 状态：Accepted
- 日期：2026-10-09
- 相关文档：架构文档 §53；实施计划 Phase 10–11

## 背景

团队资源有限，悬浮窗与拖放体验强依赖平台细节；同时架构要保持可跨平台。

## 决策

MVP 以 Windows 为第一目标并发布；macOS / Linux 在 CI 中作为非阻塞构建，保持代码可编译，待 Phase 11 补齐 Adapter 与视觉回归后转为必需。不追求各平台实现完全一致，允许降级，但行为差异需记录在兼容矩阵中。

## 后果

- 好处：集中精力打磨首个平台的核心体验。
- 代价 / 风险：非 Windows 平台问题发现较晚，需要靠 Port 边界与非阻塞 CI 控制成本。
- 替代方案：三平台同时开发（MVP 周期过长）。
