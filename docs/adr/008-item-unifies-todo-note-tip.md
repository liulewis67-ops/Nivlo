# ADR-008 Item Unifies Todo Note Tip

- 状态：Accepted
- 日期：2026-10-09
- 相关文档：架构文档 §8；产品文档 §16–17；实施计划 0.5

## 背景

Todo、Note、Tip 共享标题、描述、来源、标签、项目、时间等大部分属性，分开建模会造成重复与转换成本。

## 决策

使用统一的 `Item` 聚合，以 `ItemType { Todo, Note, Tip }` 区分；类型特有规则（Todo 可完成、Tip 不可完成、转换时清理状态）在 Domain 层用方法表达，非法状态不可构造。

## 后果

- 好处：Inbox、搜索、标签、Calendar 等能力天然对三种类型通用；类型转换简单。
- 代价 / 风险：需要通过领域规则与测试防止字段在错误类型上被误用。
- 替代方案：三张独立表 / 三个聚合（重复与跨类型功能复杂）。
