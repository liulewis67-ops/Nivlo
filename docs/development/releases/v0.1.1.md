# StarDeskBox 0.1.1

本次更新改善创建事项、查看详情与关联文件的体验。

## 新增与改进

- 在详情中直接只读预览关联图片和文本，列出全部关联文件，并可定位到文件夹。
- 主窗口内的事项详情在主内容区展示，关闭后返回原页面。
- 从悬浮面板或全局搜索打开详情时使用独立窗口；同一事项复用窗口，不同事项可分别查看。
- 独立详情窗口使用与主窗口一致的自绘标题栏，支持拖动、最小化和最大化。
- 关闭详情前等待自动保存，保存失败时保留草稿；删除后仍可撤销。

## 修复

- 修复创建窗口从悬浮徽标打开时的滚动错位与横向溢出。
- 创建窗口可通过标题区拖动，表单控件不会误触窗口拖动。
- 修复悬浮面板中的事项标题无法点击查看详情的问题。

## 安装与升级

下载并运行 该版本 Release 中的 Windows x64 安装包。支持 Windows x64，可覆盖安装；用户数据保留在原数据目录。

内置预览支持 16 MiB 以内的 PNG、JPEG、GIF、WebP、BMP 图片，以及 512 KiB 以内的 UTF-8 / UTF-16 文本。其他格式可在文件夹中查看。
