# StarDeskBox 0.1.2

本次更新修复应用内更新与 GitHub Release 的连接，后续版本可直接在应用中检查并安装。

## 修复与改进

- 修复检查更新因缺失更新清单而无法获取新版本的问题。
- 更新包提供与现有客户端公钥匹配的签名，下载后由应用校验。
- 更新提示使用对应版本的发布说明。
- 发布流程强制检查安装包、签名及更新清单是否齐全，并验证真实 GitHub 下载与签名，避免再次发布无法在应用内更新的版本。

## 安装与升级

已有用户可在主窗口「设置 → 关于 → 检查更新」中获取本版本，也可等待主窗口加载后的自动检查提示，确认后安装。升级前应用会备份当前数据，验签通过后静默安装并重启。

也可下载并运行 该版本 Release 中的 Windows x64 安装包，支持 Windows x64，可覆盖安装并保留用户数据。

更新包签名与 Windows Authenticode 代码签名不同；本安装包仍未配置 Authenticode 证书，Windows 可能显示发布者未知。
