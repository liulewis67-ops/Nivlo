# Nivlo 拾序 0.1.0

Nivlo 的首个公开版本，面向 Windows x64，把桌面上的零散信息收集、整理为可执行的下一步。

- 悬浮捕获：拖入链接、文字、图片、文件和文件夹，支持粘贴与快捷键。
- 收件箱：将捕获内容整理为待办、笔记或提示，保留来源上下文。
- 今日与日历：安排任务、调整顺序、设置提醒，集中处理今日事项。
- 搜索与命令：快速查找内容，支持键盘操作。
- 捕获工作流：按规则处理常见来源，支持 JavaScript 脚本与 Jira / GitHub 集成。
- 个性化：中英文、深浅主题、悬浮窗皮肤与动画配置。
- 本地数据：SQLite 存储、备份、导入导出与回收站。

## 安装

下载 `Nivlo_0.1.0_x64-setup.exe` 并运行，安装到当前用户目录，无需管理员权限。

本版本未配置 Windows Authenticode 代码签名，Windows 可能显示发布者未知。更新包的 Tauri 签名用于应用内更新校验，与 Windows 代码签名不同。

## 平台与边界

- 本次仅提供 Windows x64 安装包，macOS / Linux 暂不提供下载。
- 数据默认保存在本机；网页获取及外部集成需要联网。
- 宣传页的交互演示使用示例数据，不会创建桌面应用中的真实任务。
- 这是 0.x 初始版本，后续接口和行为仍可能调整。升级前建议保留数据备份。
