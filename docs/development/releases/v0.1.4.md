# StarDeskBox 0.1.4

- 修复 Nivlo 旧用户升级后提示“无法升级本地数据库”、应用无法启动的问题。更名时历史迁移脚本的注释发生变化，导致 SQLx 校验和不匹配；现在精确兼容已发布脚本，不重写旧库的迁移记录。
- 已使用 StarDeskBox 0.1.3 创建的数据库继续正常使用，未知校验和仍会触发保护性报错。
- 即使 StarDeskBox 新目录已经存在，只要其中尚无数据库，仍会识别并使用原 Nivlo 数据库及附件目录。
- 兼容 `NIVLO_DATA_DIR` 自定义数据目录，新变量 `STARDESKBOX_DATA_DIR` 优先。

如果 0.1.3 因数据库迁移失败而无法打开，请下载安装此版本后重试。无需删除旧数据库、清空数据或手动修改迁移记录。

Fixes startup failures when upgrading pre-rename databases, preserves existing migration history and attachment paths, and supports databases created by StarDeskBox 0.1.3.
